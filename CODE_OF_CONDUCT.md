# Code of conduct

Mesh-to-CAD follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in the project, in issues, pull requests, discussions or any other
channel, is expected to follow it.

## Reporting

Report unacceptable behaviour privately to the maintainers, through the contact on the
maintainers' GitHub profiles or a private message on GitHub. Reports are handled confidentially.
The maintainers decide on consequences as described in the enforcement guidelines of the
Contributor Covenant.
