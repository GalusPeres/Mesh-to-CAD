# Research

Background the product decisions rest on. Read before planning or building a tool.

| File                                           | What it covers                                                                                                                                          |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [quicksurface.md](quicksurface.md)             | QuickSurface, the reference product: end-to-end workflow, every tool with its exact UX and sources, pain points, how to be easier, algorithms, licences |
| [recognition-papers.md](recognition-papers.md) | Literature and algorithms for reading a scan like a designer: segmentation, primitives, blends, design intent, feature trees                            |

Every tool in section B of `quicksurface.md` has a GitHub issue (label `qs-parity`) in the
milestone of its workflow step. A tool counts as done when its issue is closed: built,
tested, shown working in the app on a real scan.
